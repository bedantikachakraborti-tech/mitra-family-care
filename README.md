# Mitra Care Connect

Build the initial Mitra application shell and visual design.

Mitra is a mobile-first progressive web application. The primary user is a caregiver using the application on their phone throughout the day, while families should also be able to use it comfortably on desktop.

Brand:

- Name: Mitra

- Tagline: "Care is better together."

The visual identity should feel:

- warm

- human

- trustworthy

- calm

- welcoming

- accessible

Avoid making it look like:

- a hospital

- an insurance platform

- a corporate HR system

- a surveillance application

Use:

- rounded cards

- generous spacing

- friendly typography

- subtle illustrations/icons

- clear visual hierarchy

- large touch-friendly buttons

Create these initial pages:

1. Landing page

2. Role selection

3. Caregiver onboarding

4. Family onboarding

5. Family dashboard

6. Caregiver dashboard

7. Caregiver profile

8. Family care request

9. AI matching results

10. Shared care dashboard

11. Care plan

12. AI assistant

Navigation should work on both mobile and desktop.

On mobile:

- use a simple bottom navigation or similarly intuitive mobile navigation

- prioritize Today's Care, Care Plan, Assistant, and Profile for caregivers

On desktop:

- use a sidebar or top navigation

Use realistic fictional demo data where necessary.

Do not implement fake AI functionality yet.

Focus on:

- application structure

- navigation

- responsive layout

- visual design

- reusable components

Do not add social-media features, feeds, likes, followers, or unnecessary functionality.
